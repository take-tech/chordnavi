# ChordSketch（ChordNavi の派生：1曲単位のコード譜と MIDI を作る作曲支援アプリ）

## このフォルダについて

- ChordNavi と同じリポジトリで作る別製品。音楽理論（`ui/theory.js`）は ChordNavi と共有し、コピーしない。
- 今はブラウザで動くプロトタイプ（`sketch/prototype/`）の段階。**UI・挙動はこのプロトタイプを正とする**（ChordNavi の `reference/prototype.html` と同じ扱い）。
- 確認：リポジトリのルートを HTTP で配信して `http://localhost:8765/sketch/prototype/` を開く（`python3 -m http.server 8765`）。`../../ui/theory.js` を読むのでルートから配信すること。
- テスト：`node sketch/prototype/song.test.mjs`（曲データ・パターン・食い・範囲・SMF）。

## ファイル

```
sketch/prototype/
  index.html / style.css   … 画面。色の変数は ChordNavi と同じ名前・値
  song.js                  … 曲データと MIDI 生成の純粋関数（UI を置かない）
  player.js                … ブラウザでの試聴（WebAudio：音色・ドラム・先読みスケジューラ）。プラグインでは C++ に置き換える
  app.js                   … UI（五度圏・パレット・シート・操作・印刷・保存・MIDI 入力）
  song.test.mjs            … song.js の単体テスト
```

## 曲データ（song.js）

- `song = {title, key:{idx,mode}, bpm, meter:[n,d], pattern, octave, bassOctave, bass, sections:[…]}`
- `section = {id, name, color, bars, pattern|null, chords:[…], marks:[…]}`。セクションは小節の並びで、並べ替え・複製ができる。
- `chord = {id, bar, pos, len, off, q, boff?}`：`bar` はセクション内の小節、`pos`・`len` は tick（4分音符＝480）。`off`・`boff` は主音からの半音数（ChordNavi の `chordAt` と同じ）なので、キーを変えると度数を保って移調する（「音名を保つ」オンなら度数を付け替えて音名を保つ）。長さは小節をまたげるが、セクションの終わりで切る。
- `mark = {bar, pos, bpm}`（テンポ：任意の位置。半拍単位）／`{bar, pos:0, meter}`（拍子：小節の頭のみ）。変更はセクションの並び順に流れる。1小節目の値は `song.bpm`・`song.meter`。
- 配置は上書き：重なった前のコードは切る（長いコードの途中なら前後に分ける）、後ろのコードは頭を削る、中に収まるコードは消す。長さの変更は次のコードの頭まで。

## MIDI 生成

- SMF フォーマット0、分解能480。テンポ（FF 51）・拍子（FF 58）を入れる。範囲を書き出すときは、先頭にその位置のテンポ・拍子を入れ、範囲の頭にかかる音は頭から鳴らし直す。トラックの長さは範囲の長さ。
- ボイシングは ChordNavi と同じ（ベース＝C2〜B2、上声＝ルートを C3〜B3 に置いて積む）。上声・ベースは別々に −2〜＋2 オクターブ、ベースは出す／出さないを切り替えられる。
- パターン（`PATTERNS`）：全音符・2分音符・4分刻み・8分刻み・ポップ（ベース＋裏拍）・シンコペーション（3・3・2）・アルペジオ（8分）・バラード（4分の分散）。1小節（1920 tick）を1周として小節の頭から繰り返し、小節の終わりで切る。曲全体の既定に加えて、セクションごとに上書きできる。
- **食い（シンコペーション）**：パターンの音が無い位置から始まるコードは、頭に和音を足す。それが小節線の1拍以内前なら、小節頭の音を鳴らし直さずにタイで伸ばす（同じコードの中、または次の同じコードへ。セクションをまたいでもよい）。
- ファイル名は日本語を使わない：`<キー>_<曲名の英字>_<範囲>.mid`（範囲は `Song`／セクションの英字名（Aメロ→Verse、サビ→Chorus…）／`Bar5-8`）。
- メトロノーム・ドラムは試聴のみで、MIDI には入れない。

## 画面と操作

- 1280×780 の固定ステージを縦横比を保って拡縮（ChordNavi と同じ）。シートだけは縦にスクロールする。
- 左：五度圏（ChordNavi と同じ見た目）・キー、ダイアトニック（4和音／3和音）、コードを作る（ルート・種類・ベース）、MIDI 入力（判別・ステップ入力）、試聴の音色。
- パレットのコード：クリックで試聴、ダブルクリックでカーソル位置に入力、シートへドラッグで配置。カーソルがあれば数字キー 1〜7 でダイアトニックを入力して、入力の長さだけ進む。
- シート：セクションごとに1行 4／8 小節で折り返す（コード譜と同じ見た目）。スナップは 1小節／1拍／半拍。
  - ブロック：クリックで選択＋試聴、ドラッグで移動（Alt でコピー）、右端で長さ。拍の裏から始まるブロックには左上にオレンジの印。
  - 空いたところ：クリックでカーソル、横にドラッグ・Shift＋クリックで小節の範囲。小節番号：クリック・ドラッグで範囲、ダブルクリックでテンポ・拍子の変更。
  - キー：Space 再生／停止、⌫ 削除、←→ 移動（⇧ で長さ）、↑↓ 半音、⌘Z／⇧⌘Z、⌘C／X／V、⌘D 複製、⌘A 全選択、Esc 解除、Home 先頭。
- 再生：選択範囲（なければカーソルの小節から最後まで）。ループ、カウントイン（1小節）、メトロノーム（クリック・8ビート・16ビート・シャッフル）。
- MIDI：ツールバーの「⠿ …をドラッグ」（選択範囲、なければ曲全体）、各セクションの「⠿ MIDI」、「MIDI保存」。ブラウザでは Chrome の `DownloadURL`、プラグインでは ChordNavi と同じ C++ の外部ドラッグ。
- コード譜：「コード譜 PDF」でプレビュー（A4・1行4小節・セクション名・テンポ／拍子の変更・度数の有無）、そこから印刷／PDF 保存。
- 保存：ブラウザでは localStorage に自動保存。ファイルは `.chordsketch`（JSON：`{app:'ChordSketch', v:1, song}`）。元に戻す／やり直しは曲データのスナップショット。
