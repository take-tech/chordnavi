# ChordSketch（ChordNavi の派生：1曲単位のコード譜と MIDI を作る作曲支援アプリ）

## このフォルダについて

- ChordNavi と同じリポジトリで作る別製品。音楽理論（`shared/ui/theory.js`）・五度圏（`shared/ui/wheel.js`）などは ChordNavi と共有し（`shared/`、ルートの CLAUDE.md）、コピーしない。
- 今はブラウザで動くプロトタイプ（`sketch/prototype/`）の段階。**UI・挙動はこのプロトタイプを正とする**（ChordNavi の `reference/prototype.html` と同じ扱い）。
- **プロトタイプの仕様は 2026-09-29 に確定**（タグ `chordsketch-prototype-1`）。JUCE 化はこの状態を正として進める。仕様を変えるときは、先にプロトタイプとこのファイルを直してから JUCE 側に反映する。
- 確認：リポジトリのルートを HTTP で配信して `http://localhost:8765/sketch/prototype/` を開く（`python3 -m http.server 8765`）。`../../shared/ui/` を読むのでルートから配信すること。
- テスト：`node sketch/prototype/song.test.mjs`（曲データ・パターン・食い・範囲・SMF）。
- `app.js` を変えたら文法を確かめる（書き間違いがあると画面全体が動かなくなる）：`cp sketch/prototype/app.js /tmp/app.mjs && node --check /tmp/app.mjs`

## JUCE 版（Standalone のみ）

- CMake のターゲット `ChordSketch`（`ChordSketch_Standalone`）。プラグインのコード `Cdsk`（メーカー `Rnze`）、表示名「ChordSketch」、バンドル ID `com.ranze.chordsketch`、バージョン 0.1.0、アイコンは `sketch/assets/icon/ChordSketch.png`（案 B：五度圏＋タイムライン。全面（1024 の正方形いっぱい、余白・角丸なし。角は macOS が丸める。macOS 26 で白い枠に入れられないように）の元データは `icon_B_full.svg`、角丸の板の版は `icon_B.svg`、ほかの案 A・C も同じフォルダ）。アイコンを変えたら CMake の設定をやり直す（icns は設定のときに作られる）。設定ファイルは `~/Library/Application Support/ChordSketch.settings`、Windows の WebView2 のデータは AppData の `ChordSketch/WebView2`。
- UI は `sketch/prototype/` の html・js・css をそのまま埋め込む（`ChordSketchUIData`。共通の `shared/ui/` と JUCE の JS も）。プロトタイプを正とするのでコピーしない。
- C++ は `sketch/Source/`：`SketchProcessor`（今は無音。画面の状態 JSON を `PluginState` で預かる）、`SketchEditor`（WebView。`WebResources` で配信）、`SketchStandaloneApp`（ChordNavi と同じネイティブのタイトルバー、メニュー「オプション → オーディオ／MIDI の設定…」）。
- 「ウィンドウを広げたとき」（テーマのメニュー。`ui.scaleMode`）：「全体を拡大」（既定、下の拡大縮小）か「広げる」（ページのズームを 1 より大きくしない。基準より大きいウィンドウでは画面を横にも縦にも広げ、左のパネルの幅はそのままでシート・ピアノロールが広がる。基準より小さいときは全体を縮める）。JS の `fit()` と C++ の `updateZoom()`（`setScaleMode`）で同じ決まり。
- 拡大縮小：macOS では WKWebView のページのズーム（`shared/cpp/WebViewZoom.mm`）をウィンドウの大きさ÷1280×780 にして、画面側からはいつも基準の大きさに見せる（CSS の拡大縮小は倍率 1 のままなので文字がにじまない。座標の計算も変わらない）。Windows は画面側の CSS の拡大縮小（`fit()`：倍率が 1 にほぼ等しければ 1、位置は整数ピクセル）。
- ネイティブ関数（`SketchEditor`）：`startMidiDragBytes({name,data})`（data は JS の `buildSmf` の SMF を base64。一時フォルダの `ChordSketch/` に書いて OS のファイルドラッグ）、`saveMidiBytes({name,data})`（保存ダイアログ。拡張子 .mid が無ければ付ける）。JS は `shared/ui/juce-bridge.js` があるとき（JUCE 版）だけ使い、MIDI のドラッグは押して 4px 動かしたら始める（WebView では HTML のドラッグを使わない）。ブラウザでは Chrome の `DownloadURL` とダウンロード。
- 試聴（JUCE 版）：`SketchProcessor` が `PreviewSynth`（単発のコード・MIDI 鍵盤）と `SongPlayer`（曲）を鳴らす。`player.js` は曲全体の予定表（秒。ノート [開始, 長さ, 音, 強さ]、ドラム [開始, 種類]、カウントインは負の時刻のクリック）を `songPlay` で渡し、再生中の変更・ループの切り替えは `songUpdate`、止めるのは `songStop`。位置は 30Hz の `songPos`（あいだは経過時間で補う）。音色は C++ の 6 種類（ブラウザは WebAudio の 4 種類）。単発は `previewNotes`、ミュートは `setMute`、MIDI 鍵盤の音色は `setTimbre`。
- MIDI 鍵盤（JUCE 版）：C++ が鳴らし（サステインペダル対応）、押している鍵盤（ペダルで伸ばしている音は含めない）を 30Hz の `midiNotes` で送る。コード判別・ステップ入力は JS（ブラウザは Web MIDI）。
- 曲ファイル（JUCE 版）：`songOpen()` → `{path,name,text}`、`songSaveAs({name,text,path})` → `{path,name}`（どちらもネイティブのダイアログ。拡張子 .chordsketch が無ければ付ける。取り消しは "cancelled"）、`songWrite({path,text})`（上書き保存）。書き込みは一時ファイルに書いてから置き換える。JS の `fileHandle` はブラウザではファイルのハンドル、JUCE 版はパスの文字列。同じパスのファイルを開いたらそのタブに切り替える。
- 自動保存（JUCE 版）：開いているタブ全部（曲・ファイル名・パス・未保存の印）と画面の設定を `loadSession()`／`saveSession(json)` で `~/Library/Application Support/ChordSketch/session.json`（Windows は AppData の `ChordSketch/session.json`）に。ブラウザは localStorage。session.json が無いときは WebView の localStorage を読む（前の版からの引き継ぎ）。パスを覚えているので、起動し直しても上書き保存できる。
- JUCE の WebView（macOS）は `alert()`・`confirm()`・`print()` を扱わないので使わない（印刷は `printPage`）：確認は画面の中のダイアログ（`askDialog`）、知らせはトースト。
- ビルド：`cmake --build build --target ChordSketch_Standalone`。`build/ChordSketch_artefacts/<構成>/Standalone/ChordSketch.app`。
- 曲ファイルの関連付け：macOS は `DOCUMENT_EXTENSIONS chordsketch`（Info.plist）、Windows はインストーラーのレジストリ。ダブルクリックで開いたファイルは `SketchStandaloneApp`（起動時のコマンドライン・`anotherInstanceStarted`）→ `SketchProcessor::queueOpenFiles` → エディタが JS に渡す（JS が起動時に `takeOpenFiles()` を呼んだあとは 30Hz のタイマーで `openFiles` イベント）。起動中なら新しいタブ、もう開いていればそのタブへ。
- 印刷：macOS は `printPage`（上）。Windows の WebView2 は JS の `print()` で印刷画面が出るので、`printPage` が false を返したら `print()`。
- 配布：macOS は `./scripts/package_sketch_macos.sh`（`build-release/packages/ChordSketch-<ver>-macOS.pkg`。/Applications に入れる。署名・公証の環境変数は ChordNavi と同じ）。Windows は Inno Setup の `installer/windows/ChordSketch.iss`（Program Files、スタートメニュー、.chordsketch の関連付け、WebView2 ランタイムが無ければ案内）。タグ `sketch-v*` を push すると `.github/workflows/sketch-release.yml` が両方を作って GitHub Release に添付する（ChordNavi の `v*` とは別。手動実行では成果物だけ）。

## 曲データ（song.js）

- `song = {title, key:{idx,mode}, bpm, meter:[n,d], pattern, voicing, guitarArea, octave, bassOctave, bass, sections:[…]}`
- `section = {id, name, color, bars, pattern|null, chords:[…], melody:[…], marks:[…]}`。セクションは小節の並びで、並べ替え・複製ができる。
- セクションの移動：左の色の棒をつかんで上下にドラッグ（見出しの ↑↓ でも可）。落とす位置（セクションの間）に線を出し、動かしているセクションは薄くする。シートの上端・下端に近づけると自動でスクロール。Esc で取り消し。移動後はそのセクションを範囲選択にする。
- タブの間の移動：セクションの色の棒をつかんで別の曲のタブの上で放すと、その曲の最後へ移動（⌥ でコピー）。タブが光り、放すと知らせ（トースト）。コード名と小節の中の位置が変わらないよう、付け先の最後のキー・拍子と違えばセクションの頭にキー・拍子の変更点を付ける（テンポは付け先に合わせる。`appendSectionFrom`）。移動元・移動先それぞれで元に戻せる。
- 「次と結合」（`mergeSections`）：次のセクションを後ろにつないで1つにする（複製したサビを1つのサビにするなど）。名前・色・パターンは前のセクション。後ろのコード・変更点は小節をずらして引き継ぎ、パターンが違えば後ろのコードに元のパターンをコードごとのパターンとして付ける（MIDI は結合前と同じ）。結合したセクションの中の、直前と同じ値の変更点は消す（`pruneMarks(song, si)`）。結合後はそのセクションを範囲選択にする。
- 「分割」（`splitSection`）：カーソルのある小節の頭でセクションを2つに分ける（見出しの「分割」または下のバーの「✂ ここで分割」。セクションの2小節目以降にカーソルがあるとき）。後ろは同じ名前・色・パターン。分け目をまたぐコードは2つに切る。分けた後ろの名前欄にフォーカスする。
- セクションの名前は自由記述。追加はシート末尾の入力欄（名前＋小節数、Enter か「＋ 追加」。空欄では追加しない）。定番名（Intro・Aメロ・Bメロ・サビ・間奏・Cメロ・落ちサビ・Outro）のボタンは入力欄に入れるだけ。色は定番名ならその色、それ以外は直前のセクションの次の色。追加後も見出しの名前欄で変えられる。
- `chord = {id, bar, pos, len, off, q, boff?, pattern?}`：`bar` はセクション内の小節、`pos`・`len` は tick（4分音符＝480）。`off`・`boff` は主音からの半音数（ChordNavi の `chordAt` と同じ）なので、キーを変えると度数を保って移調する（「コード固定」オンなら度数を付け替えてコード名（鳴る音）を保つ）。長さは小節をまたげるが、セクションの終わりで切る。
- `mark = {bar, pos, bpm}`（テンポ：任意の位置。半拍単位）／`{bar, pos:0, meter}`（拍子：小節の頭のみ）／`{bar, pos:0, key:{idx,mode}}`（キー：小節の頭のみ）。変更はセクションの並び順に流れる。1小節目の値は `song.bpm`・`song.meter`。
- **スケール**：キーと一緒に持つ（`key.scale`。無ければモードの既定＝メジャー／ナチュラル・マイナー、`keyScale`）。選べるのは ChordNavi の `SCALES` のうちコードトーン以外の15種（`SKETCH_SCALES`）。左パネルのキーの下で、カーソルのある範囲（曲の頭か途中のキーの変更点）のスケールを変える（コードは変えない）。キーのモードを変えたら既定のスケールに戻す（ChordNavi と同じ）。
  - 7音のスケール（`CONFORM_SCALES`）：ダイアトニックをそのスケールで作る（`diatonicOf`）。プリセットも既定と違うスケールなら作り直す（`conformBars`。ChordNavi の「スケールに沿う」と同じ計算。ChordSketch ではスケールを選ぶこと自体で切り替えるのでボタンは無い）。
  - それ以外（ペンタ・ブルース・ホールトーンなど）：ダイアトニックはモードのまま、スケールの外の音を含むコードは薄く出す。
  - スケールから入れたコードは度数番号 `deg` を持つ（ロクリアンの ♭V などを正しく書く。`chordAt` の4つめ）。ルートを変える・度数を付け替える移調をすると外す。コピー・プリセットでも引き継ぐ。
  - 五度圏の中央の下の行は、既定と違うスケールならスケール名。
- **途中のキー変更（転調）**：コードの `off`・`boff` は、そのコードが始まる小節のキー（`timeline` の `bars[].key`）の主音が基準。表記・度数・MIDI はその位置のキーで決まる（`placedChords` の `key`、`nameOf(song, c, key)`）。
  - 追加・変更・削除はポップアップの「キー（小節の頭）」（曲の頭のキーは五度圏で変える）。「後ろのコードも移調する（度数を保つ）」オン（既定。「コード固定」オンのときはオフ）なら度数を保ってコードも移る（最後のサビを1音上げる、など）。オフなら、影響する範囲（その小節〜次のキーの変更点）のコードの度数を付け替えて鳴る音を保つ（`setKeyMark`）。
  - 五度圏・キーの選択・ダイアトニック・プリセット・コード作成・MIDI 入力は、カーソルのある場所のキー（`curKey`）。五度圏の中央に「メジャー・9小節〜」のように範囲の頭を出す。五度圏でキーを変えると、カーソルのある範囲（`keyRegion`）のキー（曲の頭の範囲なら `song.key`、途中なら その変更点）を変える。
  - コードの移動・コピーは度数を保つ（別のキーの範囲に動かすと、そのキーで同じ度数になる）。ファイル名・印刷の見出しは曲の頭のキー。タグは紫の「Key B」、印刷にも「Key: B」。
- 直前に効いている値と同じになった変更点（タグ）は消す（`pruneMarks`。キーも対象。曲の頭から順に見るので、前の変更点を外していらなくなった後ろの変更点も消える。前に別の値への変更があれば「そこから戻す」変更点として残る）。テンポ・拍子を変えたとき（ポップアップ、上部の ♩=・拍子）に呼び、セクションの並べ替え・削除では呼ばない。
- 配置は上書き：重なった前のコードは切る（長いコードの途中なら前後に分ける）、後ろのコードは頭を削る、中に収まるコードは消す。
- 長さの変更（右端・⇧＋←→、`stretchChord`）と頭の位置の変更（左端・⌥⇧＋←→、`stretchChordStart`。終わりはそのまま。前に伸ばすと前のコードを上書き、セクションの頭より前には伸ばさない）。どちらも最大2小節（始まる小節の拍子で）。伸ばした先のコードは上書き。ドラッグ中はドラッグ前の状態から毎回やり直すので、縮め直すと上書きしたコードが戻る。

## MIDI 生成

- SMF フォーマット0、分解能480。テンポ（FF 51）・拍子（FF 58）を入れる。範囲を書き出すときは、先頭にその位置のテンポ・拍子を入れ、範囲の頭にかかる音は頭から鳴らし直す。トラックの長さは範囲の長さ。
- ボイシング（`song.voicing`、「MIDI 出力」の段で切り替え。曲全体の設定）：
  - ピアノ：ChordNavi と同じ（ベース＝C2〜B2、上声＝ルートを C3〜B3 に置いて積む）。
  - ギター：ChordNavi の `ui/guitar.js` で弾けるコードフォームを探す（最低音の弦＝ベース、残りの弦＝上声）。ポジションは「Low／Mid／High」（`guitarArea`、`TAB_AREAS`）あたりで、前のコードのフォームから手の移動が少ない形（`nearestVoicing`）。同時に鳴らすベース＋和音（3音以上）は弦ごとに `STRUM_TICKS`（10 tick）ずつずらすストロークにし、拍の頭はダウン（低い弦から）、それ以外はアップ（高い弦から）、音の終わりはそろえる。フォームが見つからないコードはピアノの形。
  - ギターのアルペジオ（アルペジオ・バラード）：1拍目（小節の頭）はベースだけ。上の弦を低い方から上って下る（4本なら 0,1,2,3,2,1…。パターンが弦の番号 `g` を持っていればそれ。フォームの外の音は足さない）。弾いた弦は次に同じ弦を弾くまで鳴らしたまま（コードの終わりまで）。バラードの伸ばす和音は外す（同じ弦を2回鳴らさない）。
  - パターン・食い・オクターブは、どちらでも同じように効く。上声・ベースは別々に −2〜＋2 オクターブ、ベースは出す／出さないを切り替えられる。
- パターン（`PATTERNS`。選択欄は `PATTERN_GROUPS` のまとまりごと）：
  - 基本：全音符・2分音符・4分刻み・8分刻み
  - バンド：ポップ（ベース＋裏拍）・シンコペーション（3・3・2）・アルペジオ（8分）・バラード（4分の分散。音の高さの順で 1・2・4・3＝ベース → 上声の低い音 → 一番上 → 間の音）・ボサノバ・ワルツ（3拍子向け：1拍目ベース、2・3拍目和音）
  - EDM：オフビート（ハウス。8分の裏で和音とベース）・パンプ（サイドチェイン風。拍の少し後から次の拍まで和音、拍の頭にベース）・フューチャーベース（16分の 3・3・2 の和音、2分のベース）・トランス（16分ゲートの和音、8分裏のベース）・アルペジオ（16分・上行）
  1小節（1920 tick）を1周として小節の頭から繰り返し、小節の終わりで切る。使うパターンは「コード → セクション → 曲全体の既定」の順で決まる。コードのパターンは選んだコードの編集パネルで選び、ブロックの右上に短い名前（「8分」「シンコペ」など）を出す。複製・コピー・移動でも引き継ぐ。
- **途中から始まるコード**：パターンの中でその位置にまだ伸びているはずのベース・和音を、その位置から新しいコードで鳴らし直す（バラード・アルペジオ・4分刻みの3拍目で変わるコードでもベースと和音が鳴る）。伸びている音も無く、その位置にパターンの音も無いときは、拍の裏から始まる（食い・シンコペーション）か、次のパターンの音まで1拍より空く（鳴らないまま終わる）ときだけ、次のパターンの音まで和音を足す（拍の頭から始まるコードはパターンどおり。オフビートなど頭で鳴らさないパターンのため）。
- **食い（シンコペーション）**：その位置にパターンの音が無いときに頭に足した音は、それが小節線の1拍以内前なら、小節頭の音を鳴らし直さずにタイで伸ばす（同じコードの中、または次の同じコードへ。セクションをまたいでもよい）。
- ファイル名は日本語を使わない：`<キー>_<曲名の英字>_<範囲>.mid`（範囲は `Song`／セクションの英字名（Aメロ→Verse、サビ→Chorus…）／`Bar5-8`）。
- メトロノーム・ドラムは試聴のみで、MIDI には入れない。
- メトロノームの種類：クリック・8ビート・16ビート・シャッフル・4つ打ち（EDM。大きな拍ごとにキック、2つ目ごとにクラップ、裏にハイハット）。
- ドラム（`player.js` の `barDrums`）は拍子を大きな拍（パルス）に分けて組み立てる（`pulsesOf`）：6/8・9/8・12/8 は付点4分（8分×3）ずつ、ほかは拍ずつ。キック・スネアは2つずつ K S、奇数なら最後を K S S（`backbeat`：3/4 はワルツ、5/4 は K S K S S）。ハイハットは大きな拍を 8ビート＝2（3拍子系は3）、16ビート＝4（6）に分けて刻む。シャッフルは4分系は3連でハネ、3拍子系は3連の1つ目と3つ目。4拍子の8ビート・16ビートは今までどおりキックを足す。

- **コードのボイシングの編集**（2026-10-01）：`chord.v`＝鳴らす音（キーの基準の音 `melodyBase` からの半音の並び。無ければ自動の `voicingOf`）。いちばん低い音をベース、残りを上の音として、パターンはそのままかかる（`customNotes`・`chordVoicingNotes`）。キーを変えると度数と一緒に移調し、コード固定・キーの変更点の「鳴る音を保つ」・チップの ↑↓ では鳴る音を保つ／一緒に動かす。範囲のコピー・貼り付けにも入る。コードの編集パネルでルート・種類・ベースを変えると `v` は消す（自動に戻る）。編集済みのチップは右下に ✎。
  - 画面：チップを押したときの編集パネル（1段目：コード名・度数・閉じる、2段目：コード（ルート・種類・ベース）と「コード編集」、3段目：長さ・パターンと複製・削除）の「コード編集」で、右端に「コード編集」のパネル（コードの画面だけ）。縦の鍵盤（C1〜C7。上下に余白）で、押してすぐ離すと音を足す・消す（1音以上）、鳴らしている音を押したまま上下に動かすと別の高さへ移す（つかんだ音は浮いたバーになって、つかんだ位置のずれを保ったままポインタについてくる（行の単位で飛ばない）。行き先は浮いたバーの真ん中がある行で、うすい印（クラス名 `vdrop`。シートの `.drop` とぶつけない）、コード名もその場で変わる。確定は離したとき。行が変わったら音を鳴らす。リストの端のごく近くでは自動でスクロール。もう鳴らしている高さは飛ばす）。開いたときは、鳴らす音（いちばん低い音〜高い音）の真ん中がパネルの真ん中に来る位置。鳴らす音は青、ベース（いちばん低い音）は緑、今のコード名の構成音の行はオレンジ。マウスを乗せた行は背景を変えず（黒鍵の灰色と混ざらないように）、左端の青い線・音名・うすい青のバーで示す。変えると鳴らして、その音から `detectChords` でコード名を付け替える（判別できなければコード名はそのままでトースト）。「▶ 試聴」「元に戻す（自動）」（`v` を消す。コード名は今の名前のまま）。
- **メロディー**（2026-09-30 追加。1本だけ）：`note = {id, bar, pos, len, p, v}`。`bar`・`pos`・`len` はコードと同じ。`p` はその音が始まる小節のキーの基準の音（`melodyBase`：主音のうち C4 に近いほう、F♯4 までは上・G から下）からの半音数、`v` はベロシティ。
  - 度数と同じ考え方で、キーを変えるとメロディーも一緒に移調する（基準が近い主音に動くので大きく跳ばない）。「コード固定」・キーの変更点の「鳴る音を保つ」では、基準の音の差だけ `p` を付け替えて鳴る音を保つ（`transposeBars` の6つめ）。
  - 音は始まる位置のセクションに持たせるが、セクションの終わりでは切らない（弱起・境目をまたいで伸ばす音。ピアノロールはセクションを横につないで表示）。曲の終わりで切る（`placedNotes`・`addNote`）。
  - セクションの分割（またぐ音は前のセクションのまま後ろへ伸びる）・結合・複製・小節の挿入と削除・範囲のコピー（範囲の中で始まる音。範囲の終わりで切る）と貼り付け・タブの間の移動についてくる。音の重なり（和音）は許す。
  - 範囲は C2〜C7（`MELODY_LOW`・`MELODY_HIGH`）。
- ツールバーの2段目（コード）：音色・「出力」（パターン・ピアノ／ギター・Low／Mid／High）・上声のオクターブ・「ベース」（オン／オフ）とベースのオクターブ。オクターブは数字の右に ▲▼ を縦に並べる（ギターのときも 1280 の幅に収まるように）。
- **MIDI の書き出し**（`buildSmf` の3つめ `parts`）：「コード＋メロ」なら、メロディーがあればフォーマット1の2トラック（1トラック目：テンポ・拍子・曲名とコード、チャンネル1。2トラック目：Melody、チャンネル2）。メロディーが無い・「コードのみ」「メロのみ」ならフォーマット0の1トラック（今までと同じ）。ファイル名は、メロのみなら `_Melody`、メロディーのある曲でコードのみなら `_Chords` を付ける。

## 画面と操作

- **Space**：文字を入れる欄（曲名・小節数など）以外なら、どこにフォーカスがあっても再生／停止（録音中は録音を止める）。ボタン・選択欄・五度圏を押したあとでも効くよう capture で先に受け、ボタンが押される既定の動きは止める。確認のダイアログ・コード譜のプレビューではそちらに任せる。選択欄は選んだらフォーカスを外す（そのあとのキー操作がすぐ効く）。

- **シートのメロディー**：曲にメロディーがあれば、コードのシートの各小節のチップの段に、その小節で鳴っている音を薄い線で重ねる（チップの高さの中に収める。高さは曲全体のメロディーの範囲に合わせる。小節をまたぐ音は小節ごとに切る。`pointer-events:none` なのでチップの操作は変わらない）。
- **プリセットの進行のドラッグ**（2026-10-01）：左の「プリセット」のコードの並び（`#progNames`）をシートへドラッグ。小節の上なら、その小節から上書きで入れる（「挿入」と同じ）。何もないところ（セクションの外。「セクションを追加」の欄も含む）なら、その進行の小節数で新しいセクションを最後に作って入れる（名前は直前のセクションの次の定番の名前、Aメロ → Bメロ → サビ…、使い終わっていればまだ使っていない名前、Intro は除く）。ドラッグ中はゴーストに行き先を出し、新しいセクションなら「セクションを追加」の欄を点線で囲む。シートの上下の端では自動でスクロールする。⌘Z 1回で戻せる。
- **表示の切り替え**：ツールバーの1段目の左「コード｜メロディー」、または Tab キー（文字を入れる欄・ダイアログ・コード譜のプレビューでは使わない。カーソルの位置は引き継ぐ）。メロディーではシートの代わりにピアノロール（`roll.js`）を出し、ツールバーの中身を入れ替える（`.main.melody`、`.only-chords`／`.only-melody`）。
  - 1段目：スナップ（4分・8分・16分・3連8分。小節の頭から数える）、長さ（クリック・ステップ入力で置く音：全音符〜16分・付点・3連）、表示（横の拡大のスライダー。4分音符あたり 10〜150px を対数で。ピアノロールの上でトラックパッドを2本指で広げる・つまむでも：Chrome・WebView2 は ctrl 付きのホイール、Safari・WKWebView は gesture イベント。指・スライダーなら見えている真ん中の位置がずれないようにスクロールを合わせる。ピアノロールの横の位置・幅は tick で持ち、CSS の `calc(var(--ppt) * tick)` で並べるので、拡大は `--ppt` を変えるだけ（部品を作り直さない。止まって 200ms で描き直して音名・度数の出し分けを直す））。コードの画面ではスナップ（1小節・1拍・半拍）・長さ・表示（1行 4・8小節）。右側の「コード＋メロ／コードのみ／メロのみ」は MIDI のドラッグ・保存に入れるもの（両方の画面で共通）。
  - 2段目（メロディー）：道具（鉛筆のマーク＝描く／点線の四角＝選ぶ。⌘（Windows は Ctrl）を押しているあいだは入れ替わり、ボタンの表示とマウスの形も変わる）、メロディーの音色（既定は矩形波）、鳴らす（コード・メロディー。メロディーの画面で再生するときだけ効く。オフにすると伴奏だけで歌える）、ガイド（コードの音・スケール）。コードの音色はコードの画面の2段目。
  - ピアノロール：上にセクション・小節番号（押すとカーソル）・コードの帯（再生中のコードを光らせる）、左に鍵盤（押すと試聴）。行の色：ガイドの「スケール」がオフなら黒鍵の行を少し暗く、オンならその小節のキーのスケールの外の行を灰色（スケールの音の行は白いまま、主音の行は緑）。「コードの音」はそこで鳴っているコードの構成音をオレンジ（ルートは濃く、分数コードのベースも）にして、コードの頭にルートからの度数（R・3・♭3・5・♭7・7・9 など、ベースは B）を書く。ダークでは色を反転させず、ライトの見た目を暗くする（鍵盤は白鍵が明るく黒鍵が暗い、行はスケールの中・白鍵が明るめ）。
  - 操作（道具「描く」）：何もないところを押す→音を置いて試聴（押したまま右へ引くと長さ）、置いた音の終わりにカーソル。⇧＋ドラッグ→囲んで選ぶ。
  - 操作（道具「選ぶ」）：何もないところをドラッグ→囲んで選ぶ（⇧で今の選択に足す）、押すだけ→選択を外してそこにカーソル。
  - ドラッグ中（置く・囲む・動かす・長さ・範囲）にスクロールの端（上の帯・左の鍵盤の内側）へ近づけると、自動でスクロールして続けられる（`drag`）。
  - 結合：選んだ音を1つに（いちばん前の音の高さで、最初から最後まで。頭がそろっていれば高いほう）。分割：選んだ音を、カーソルが音の中ならカーソルで、外なら真ん中（スナップに合わせる）で2つに。⌘（Ctrl）＋クリックでその位置（スナップ）で分ける。
  - 小節番号を横にドラッグ→小節の範囲を選ぶ（コードの画面と同じ `range`。範囲の中で始まる音も選ぶ。再生・MIDI のドラッグもその範囲）。押すだけならカーソル。⌘A は曲全体の範囲とすべての音。Esc で範囲と選択を外す。
  - 下のバー：範囲があれば範囲とループ再生、選んだ音があれば数と ↑↓・消す（範囲があれば「範囲の音を消す」）・結合（2音以上）・クオンタイズ・分割・選択を外す。音を押す→選ぶ（⇧で追加・外す）、ドラッグで動かす（時間はスナップ、上下は半音）、右端をドラッグで長さ。⌥（Alt）を押しながらドラッグで複製を動かす（元の音は残り、複製したほうを選ぶ。同じ場所に落としたら複製しない）。動かさずに押して離したあと 350ms 以内にもう一度押す→消す。
  - キー：⌫ 選んだ音を消す、↑↓ 半音（⇧ でオクターブ）、←→ スナップ単位で動かす（⇧ で長さ。選んでいなければカーソル）、⌘A すべて選ぶ、⌘C／⌘X／⌘V（カーソルに貼る）、⌘D すぐ後ろに複製、Esc 選択を外す、Space 再生、Home 先頭。コードの操作（数字キー・コードの選択）はしない。
  - **リアルタイム録音**（2026-10-01）：上部の ● （R キー、メロディーの画面）。押すとメロディーの画面にして、録る位置（カーソルの小節、範囲があれば範囲の頭）の**1小節前から再生**し（プリロール。カウントインは入れない）、録る位置から MIDI 鍵盤で弾いた音を録る。曲の1小節目から録るときは前の小節が無いので、カウントイン（設定の小節数、オフでも1小節）。ループでは1小節前も含めて繰り返す。今ある音に**重ねる**（置き換えない）。止める（●・■・Space・曲の終わり・画面の切り替え）とまとめて入れて、⌘Z 1回で戻せる。録音中の音は赤でその場に伸びていく（`setRecNotes`）。プリロール・カウントイン中に弾き始めた音は録る位置から、それより前で終わった音は捨てる（表示もしない）。サステインペダルは見ない（鍵盤を離したところまで）。クオンタイズは自動ではせず、あとで選んだ音に「クオンタイズ」（Q。頭と終わりを今のスナップに、長さは1スナップ以上）。
    - 時刻：JUCE 版は C++（`SketchProcessor`）が MIDI を受けたブロックの頭の曲の位置＋ブロック内の位置（サンプル）を記録し、30Hz で `recNotes` { events:[session, 秒, 音, 強さ, 押した1/離した0, …] } を送る（`setRecording(bool)`）。ブラウザは Web MIDI を受けたときの WebAudio の時計（`player.songSeconds`）。秒は周の頭が 0、テンポの変化は `secToTick`、ループは周の長さで折り返す。
    - MIDI 鍵盤で弾く音は、メロディーの画面ではメロディーの音色（コードの画面ではコードの音色）。
  - MIDI 鍵盤のステップ入力（メロディーの画面）：弾いた音（和音なら全部）をカーソルに置いて、長さだけ進む。下のバーの「休符」でカーソルだけ進める。
  - 下のバー：範囲が無ければカーソルの位置と休符。右端に今の道具の操作のヒント。
  - メロディー向けの音色（コードにも選べる）：「矩形波」（既定。伸ばしている間は減らさず、離したら 0.12 秒ほどの余韻。C++ は `Timbre::square`、ノコギリ波を半周ずらして引く polyBLEP）と「リード」（のこぎり波2本＋ローパス。`Timbre::lead`）。C++ の予定表は `melody`（ノートと同じ形）と `melodyTimbre` を足した（`SongPlayer::Note::melody` の印で音色を分ける）。

- 画面の横幅は 1280 を基準に拡大縮小する。ウィンドウが基準（1280×780）より縦長なら、余った高さの分だけ画面を縦に伸ばす（シートが広がる。上部・ツールバー・下のバーの高さは同じ、左のパネルは下が空く）。横長なら縦に合わせて左右に余白。JUCE 版のウィンドウは縦横比を固定しない（最小 960×585、最大 2560×2340）。シートは縦にスクロールする。ChordNavi は縦横比を固定したまま。
- 上部：再生は「▶」（再生中は「■」）、ループは円を描く矢印のアイコン、ミュートは「M」（ループの横。いつも赤い文字と枠、ミュート中は赤く塗る）。
- メトロノームとカウントイン（上部、2段で幅をそろえる）：上＝メトロノームのアイコン（押してオン／オフ、`ui.metroOn`）と「▾」（種類：クリック／8ビート／16ビート／シャッフル、`ui.metro`。選ぶとオンにする）。下＝カウントインのアイコン（「••••」、カウントの表示と同じ形）と「▾」（1小節／2小節、`ui.countBars`。選ぶとオンにする。「•」は大きな拍（6/8 なら付点4分、`pulsesOf`）で数え、2小節ならその2倍。8つを超えるとき（5/4・7/8 の2小節）は今の小節の分だけ並べて前に「1/2」「2/2」。多いときは「•」を小さくし、欄の外にははみ出さない。開発用に `__countDots(cnt, meter)` で表示だけ確かめられる）。前の保存形式の `metro:'off'` はオフ・クリックとして読む。
- 位置の表示（上部、DAW のトランスポート風。左右の列は 96px ずつ。テンポは小数点1けたまで（0.1 単位。入力欄は step 0.1、つかんで上下は 3px で 1、⇧ を押しているあいだは 0.1 ずつ）。テーマによらず暗い枠に水色の数字。2列の幅を固定して数字は等幅・右そろえ、列の間に細い線）：2行×2列で「♩ テンポ｜位置（小節.拍.16分）」「拍子・キー｜経過時間（分:秒.1桁）」。カウントイン中は位置のところに拍の数だけ「•」を並べ、鳴った拍まで赤くする。再生中は再生位置、止まっているときはカーソル位置の値（途中の変更も反映）。テンポ・拍子・キーを押すと、その値を決めている場所（曲の頭なら曲全体、途中なら その変更点）の、押した項目だけの変更欄を開く（`openMarkPop(gi,pos,anchor,only)`。小節番号のダブルクリックでは全部）。テンポはつかんで上下にドラッグしても変えられる（上で速く、3px で 1 BPM。1回のドラッグで元に戻す1回、再生中はすぐ反映。動かさずに離すとテンポだけの変更欄）。曲の頭のキーは五度圏で変える。1小節目のテンポ・拍子の入力欄は無くした（この表示から変える）。
- 設定：上部右端の歯車のボタンのメニュー（見出し「テーマ」「ウィンドウを広げたとき」）。テーマ：上部右端のボタンからメニューで選ぶ（ライト／ダーク／自動（OS の外観に合わせる）。今のテーマにチェック）。ダークの配色は `:root[data-theme=dark]` に限る（要素に data-theme を付けるとその要素だけダークになるので、メニューの項目は data-v を使う）。
- 位置の表記は DAW と同じ「小節.拍.16分」（例：9小節目の3拍目の裏 → `9.3.3`。拍は拍子の分母の音符、16分は4分音符の 1/4）。上部の再生位置・下のバーのカーソル・テンポのタグ（`♩=100 @3.3`）・テンポ変更の位置の選択肢で使う。
- 下のバー（カーソル／範囲の操作だけ）：まとまりごとに区切る。カーソル：位置・「小節 ［＋ 挿入］［− 削除］」・（セクションの2小節目以降なら）「セクション ［✂ ここで分割］」。範囲：「範囲 ［▶ ループ再生］［コピー］［コードを消す］」・「小節 ［＋ 挿入］［− 削除］」。コピーしたものがあるときだけ「貼り付け」。使えないボタンは出さない。右端に「テンポ・拍子・キーは小節番号をダブルクリック」。プリセットの入力ボタンは「挿入」。
- コードの編集パネル（`chordEditor`）：パネルの外を押すと閉じる（パネルの中・選んでいるチップ・右端のコード編集・ダイアログ・ポップアップは除く。押した先の操作がそのまま効くよう、描き直さずにパネルだけ消す）。ブロックをクリック（ドラッグでない）すると、そのブロックのすぐ下（入らなければ上）に開く。コード名・度数、ルート・種類・ベース（「/音名」、ルートと同じなら分数コードにしない）、長さ［−］［＋］、パターン、複製・削除、×。Esc・× で閉じ、Enter で開き直す。パレット・数字キー・MIDI 鍵盤で入力した直後やドラッグ中は開かない。
- 左（幅 320px、ChordNavi と同じ）：五度圏（ChordNavi と同じ見た目。縮めない。最大 248px。扇形のフォーカスは枠を出さず、キーボード操作のときだけ縁取り。元に戻す・ファイルを開くでもキーの位置まで回す）・キー、ダイアトニック（4和音／3和音。右上に数字は出さない。度数で分かるので）、コード作成（ルート・種類・ベース。ベースの選択肢は「/A」表記で「なし」は無く、既定はルートと同じ音。ルートを変えたとき、ベースがルートと同じなら一緒に動かし、分数コードならそのまま）、プリセット（定番コード進行）、MIDI 入力（判別・ステップ入力）。試聴の音色はツールバーの1段目。
- コード名が入りきらないとき（パレット・進行のミニ譜面）は、その要素だけ文字を小さくする（`fitText`。幅は Range で測る）。
- プリセット（定番コード進行）：1行4小節のミニ譜面で表示（長い進行も見切れない。1小節に2コードは「Gm7♭5-C7」のように「-」でつなぐ）。ChordNavi の `PROGRESSIONS`（定番／その他、派生形も）を今のキーのモードで選ぶ。「試聴」は曲の設定（パターン・オクターブ・音色）とカーソル位置のテンポ・拍子で鳴らす。「カーソルの小節から入れる」で上書き（1コード＝1小節、1小節に複数なら等分。曲の最後を越えるときは最後のセクションの小節を増やす）。入れた小節を範囲選択にする（`insertProgression`）。
- セクションの色：見出しの ● を押してパレット（8色）から選ぶ。
- パレットのコード：クリックで試聴、ダブルクリックでカーソル位置に入力、シートへドラッグで配置。カーソルがあれば数字キー 1〜7 でダイアトニックを入力して、入力の長さだけ進む。
- シート：セクションごとに1行 4／8 小節で折り返す（コード譜と同じ見た目）。スナップは 1小節／1拍／半拍。
  - 各小節の下に「カーソル帯」（ブロックの下の細い帯）。ブロックで埋まった小節でも、ここはいつでもクリックでカーソル・横にドラッグで範囲。マウスを乗せると、カーソルが入る位置（スナップ）を薄い線で出す。
  - ブロック：クリックで選択＋試聴（クリックした位置（スナップ）にカーソルも置く）、ドラッグで移動（Alt でコピー）、右端で長さ、左端で頭の位置（次の小節頭のコードを半拍前へ伸ばせば食い）。拍の裏から始まるブロックには左上にオレンジの印。
  - 空いたところ：クリックでカーソル、横にドラッグ・Shift＋クリックで小節の範囲。小節番号：クリック・ドラッグで範囲、ダブルクリックでテンポ・拍子の変更。
  - キー：Space 再生／停止、M ミュート、⌫ 削除、←→ 移動（⇧ で長さ）、↑↓ 半音、⌘Z／⇧⌘Z、⌘C／X／V、⌘D 複製、⌘A 全選択、Esc 解除、Home 先頭。
- 再生：選択範囲（なければカーソルの小節から最後まで）。ループ、カウントイン（1小節）、メトロノーム（クリック・8ビート・16ビート・シャッフル）。
- 「ミュート」（上部、M キー）：ChordSketch の出力をすべて無音にする（試聴・メトロノーム・MIDI 鍵盤。再生と表示は進んだまま）。状態は保存しない（ChordNavi と同じ）。
- 再生中の変更（音色・メトロノーム・パターン・オクターブ・コードの編集・テンポ）はすぐ反映する（`player.refresh()`）。予約済みの少し先（約0.15秒）から後ろを作り直し、鳴っている音はそこで離して、まだ続くはずの新しい音をそこから鳴らす（全音符の途中で変えても途切れない）。
- MIDI：ツールバーの「⠿ …をドラッグ」（選択範囲、なければ曲全体）、各セクションの「⠿ MIDI」、「MIDI保存」。ブラウザでは Chrome の `DownloadURL`、プラグインでは ChordNavi と同じ C++ の外部ドラッグ。
- コード譜：「コード譜」でプレビュー（A4・1行4小節・セクション名・テンポ／拍子／キーの変更・度数の有無）、そこから印刷／PDF 保存。
  - コード名は小節の中の位置に書く。小節の半分（偶数拍子）または各拍（奇数拍子）に小さな縦棒。
  - 食い（小節の終わりまで1拍未満から始まり、次の小節へ続くコード）は、次の小節の頭に「<」付きで書き、前の小節には書かない。ちょうど1拍前から始まるコードは食いとせず、その位置に書く。
  - 前からの続きのコードは、小節の頭のほうで別のコードが始まらないときだけ灰色で書く。
  - シンコペーション（拍の裏から始まるコード。食いも含む）は名前の上に「＞」。記号を使っているときは見出しの下に説明（「＞ 拍の裏から（シンコペーション）」「< 前の小節から先に鳴る（食い）」）。シートのブロックは左上のオレンジの三角とツールチップで示す。
  - プレビューを出したあと実際の幅を測って詰める（`layoutPrint`）：右からはみ出す名前は右端にそろえ、それでも入らなければ小さく（8pt まで）。前の名前と重なるときは、大きいほうから交互に小さくして大きさをそろえ、それでも重なれば右へずらす。
- タブ（Standalone・ブラウザ版だけ。プラグイン版は `TABS=false` で1曲だけ）：シートの上に開いている曲のタブ（曲名・保存していない変更の「●」・×）と「＋」。タブごとに曲・元に戻す／やり直し・カーソル・選択・スクロール位置・保存先ファイル・「●」を持つ（表示中の曲は `song`・`undoStack` などの変数をそのまま使い、切り替えで `docs` と入れ替える：`stashDoc`／`loadDoc`）。試聴などの設定とコピーしたコードは全部のタブで共通。新規・サンプル・開くは新しいタブで開く（今のタブが何も入力していない新規の曲ならそこに開く）。新規の曲の名前は「newsong」（`NEW_TITLE`）。保存していない変更があるタブを閉じるときは確認する。切り替えると再生は止める。自動保存は開いているタブ全部（`{docs:[{song,file}], active, ui}`。前の形式 `{song, ui}` も読める）。
- 曲ファイル：ファイルのメニューに「開く…（⌘O）」「上書き保存（⌘S）」「名前を付けて保存…（⇧⌘S）」。上書き保存はいま開いている（前に保存した）ファイルに書き込み、まだ無ければ名前を付けて保存。ブラウザでは File System Access API（`showSaveFilePicker`・`showOpenFilePicker`）があれば同じファイルに書き込み、無ければ名前を付けて保存は名前を聞いてダウンロード、上書き保存は同じ名前でダウンロードし直す（JUCE 版はネイティブのファイルに書く）。保存していない変更があるときは曲名の横に「●」、ファイルのボタンのツールチップに今のファイル名。
- 名前を付けて保存：「MIDI保存」と、File System Access API が無いときの曲ファイルの保存は名前を聞く（既定は自動の名前）。拡張子（`.mid`／`.chordsketch`）が無ければ自動で付ける（`withExtension`：大文字小文字は区別しない、使えない文字 `/ \ : * ? " < > |` は `_`、末尾の空白・ドットは外す、空なら既定の名前）。JUCE 版のネイティブの保存ダイアログでも同じ決まりにする。
- 保存：ブラウザでは localStorage に自動保存。ファイルは `.chordsketch`（JSON：`{app:'ChordSketch', v:1, song}`）。元に戻す／やり直しは曲データのスナップショット。
